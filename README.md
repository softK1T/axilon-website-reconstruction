# AXILON - Agencja Pracy

Profesjonalna strona internetowa dla agencji pracy AXILON w stylu [axilon.pl](https://axilon.pl) - minimalistyczny architektoniczny design.

## 🎨 Design System (axilon.pl)

### Kolory
- **Teal/Turkusowy**: `#4FBDC6` - główny akcent (logo, przyciski, hover)
- **Niebieski**: `#066aab` - secondary accent
- **Ciemny**: `#32373c` - tło, nagłówki
- **Złoty**: `#c9a962` - ikony usług (architektoniczny akcent)
- **Biały**: `#ffffff` - czysty minimalistyczny background

### Typografia
- **Font**: Jost (sans-serif)
- **Style**: Bold uppercase dla nagłówków, regular dla tekstu
- **Tracking**: Wide letter-spacing dla uppercase tekstu

### Komponenty
- Top bar z kontaktem (#32373c)
- Sticky header z logo AXILON w kolorze teal
- Rounded-full buttons (CTA)
- Minimalistyczne karty z hover effects
- Teal statistics section
- Architektoniczne ikony

## 🛠️ Tech Stack

- **React 18** - UI framework
- **Vite** - Build tool & dev server
- **Tailwind CSS** - Utility-first CSS
- **Lucide React** - Minimalist icons

## 🚀 Quick Start

```bash
# Instalacja
npm install

# Development
npm run dev

# Production build
npm run build

# Preview production build
npm run preview
```
