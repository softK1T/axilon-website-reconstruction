# AXILON - Agencja Pracy

Profesjonalna strona internetowa dla agencji pracy AXILON, zaprojektowana w minimalistycznym stylu inspirowanym axilon.pl.

## 🎨 Design

- **Styl**: Minimalistyczny, elegancki, inspirowany architekturą
- **Kolory**: Ciemny grafit (#1a1a1a), złoty akcent (#c9a962), jasne tło (#f8f8f8)
- **Typografia**: Playfair Display (nagłówki), Montserrat (tekst)
- **Layout**: Pełnoekranowy hero, duże białe przestrzenie, eleganckie animacje

## 🛠️ Tech Stack

- **React 18** - Biblioteka UI
- **Vite** - Build tool
- **Tailwind CSS** - Stylowanie
- **Lucide React** - Ikony

## 🚀 Uruchomienie

```bash
# Instalacja zależności
npm install

# Uruchomienie dev server
npm run dev

# Build produkcyjny
npm run build
```

## 📁 Struktura projektu

```
src/
├── components/
│   ├── Header.jsx      # Nawigacja sticky
│   ├── Hero.jsx        # Sekcja hero fullscreen
│   ├── Services.jsx    # Usługi agencji
│   ├── About.jsx       # O firmie
│   ├── Jobs.jsx        # Oferty pracy
│   ├── Stats.jsx       # Statystyki
│   ├── Contact.jsx     # Formularz kontaktowy
│   └── Footer.jsx      # Stopka
├── App.jsx
├── main.jsx
└── index.css
```

## ✨ Funkcjonalności

- Responsywny design (mobile-first)
- Smooth scroll navigation
- Animacje przy przewijaniu
- Formularz kontaktowy
- Karty ofert pracy
- Sticky header z efektem przewijania
